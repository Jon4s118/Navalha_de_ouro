# ✂️ Navalha de Ouro — Landing Page de Barbearia

Site de demonstração de barbearia com **lista de serviços e agendamento
via WhatsApp**. O cliente escolhe o serviço, data e horário, e o agendamento
chega pronto e formatado no WhatsApp da barbearia.

> 📄 Demo publicada: [VER AQUI](https://SEUUSUARIO.github.io/PORTIFOLIO/demos/barbearia-navalha-de-ouro/)

## 🎯 Objetivo do projeto

Segundo projeto de demonstração do portfólio — foco em landing page de
conversão para negócios de serviço local, com tema escuro/dourado
diferenciado para mostrar amplitude visual.

## ⚙️ Funcionalidades

- Grade de serviços com preços destacados
- Formulário de agendamento (nome, serviço, data e horário)
- Bloqueio de datas passadas no seletor
- Mensagem de agendamento formatada e enviada via WhatsApp
- Layout responsivo
